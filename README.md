# 🧠 BrainPannie

A modern and responsive website built using **HTML, CSS, and JavaScript**. The project focuses on creating a clean, engaging, and professional web experience with structured sections, interactive elements, and responsive design.

🔗 **Live Website:** https://brainpannie.netlify.app/

---

## 📌 About The Project

**BrainPannie** is a frontend web development project created to practice and demonstrate modern website design and development using core web technologies.

The website features a professional layout with multiple sections, smooth navigation, responsive design, and JavaScript-powered interactions.

The project was developed from scratch using:

* HTML5
* CSS3
* JavaScript
* Responsive Web Design

## 🚀 Getting Started

To run this project locally:

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

Open the project folder in **Visual Studio Code** or another code editor.

### 3. Run the website

Open `index.html` in your browser.

For a better development experience, you can use the **Live Server** extension in VS Code.
